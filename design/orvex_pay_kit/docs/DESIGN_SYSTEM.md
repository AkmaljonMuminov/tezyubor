# ORVEX PAY Premium Visual Kit

Approved visual direction: clean midnight navy, electric royal blue, luminous cyan, and silver-white payment-card emblem.

## Palette
- Midnight Navy: #06143A
- Royal Blue: #123CFF
- Electric Cyan: #18B8FF
- - Silver White: #F7FAFF
- Pale Blue: #C9D8FF

## Included
- Brand: app icon, logo mark, wordmark, splash screen
- Icons: 25 matching outlined SVG interface icons
- Banners: 4 in-app promotional banners
- Backgrounds: premium navy and gold orbit
- Social: Instagram post, story, announcement templates

## Flutter integration
The SVG files can be loaded with `flutter_svg`:
```dart
SvgPicture.asset('assets/brand/app_icon.svg')
SvgPicture.asset('assets/icons/transfer.svg')
```
Suggested asset folders:
- `assets/brand/`
- `assets/icons/`
- `assets/banners/`
- `assets/backgrounds/`
- `assets/social/`

Keep icon strokes at 1.8 units for 24x24 viewBox. Use navy backgrounds, royal blue for primary actions, and cyan for focus/active states. Brand tagline: TEZ • XAVFSIZ • QULAY.

## Important
This is a complete graphics starter kit, not a full Flutter screen implementation. Existing application screens and business logic have not been changed.
